# Triage Inbox

This adhoc app reimagines the standard Inbox as an operator-focused triage
workspace.

## What Changed

- Keeps the real conversation source of truth from the Inbox app
- Replaces the simple list/detail split with queue-aware prioritization
- Adds channel filtering, local search, flagged-only focus, and priority sorting
- Shows operational context, suggested next actions, and direct links back to the
  canonical Inbox conversation
- Keeps destructive actions scoped and explicit
