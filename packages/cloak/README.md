# @chatbotkit-dev/cloak

AES-GCM encryption, decryption, and key management for the Web Crypto API.

This package is based on
[`@47ng/cloak` v1.2.0](https://github.com/47ng/cloak/tree/v1.2.0)
(`fc619b746ce25b862d7510ad51231264516db798`). It preserves the upstream data
formats while adapting the implementation for this platform and adding features
such as additional authenticated data support.
